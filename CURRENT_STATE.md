# Current state

Last verified: 2026-08-24

This is the short operational truth for a fresh contributor. It is not a
changelog or design history. When it disagrees with an older spec or review,
this file and the current code win. Start at [the documentation map](docs/README.md)
for task-specific authority.

## Public site

- `bitterclip.com` is generated by Nuxt and served as a static nginx site.
- The homepage is `app/pages/index.vue`; its canonical visual acceptance surface
  is `/`, not `/lab/iso4`.
- Creator documentation is authored in `content/` and rendered through
  `app/pages/docs/[...slug].vue`.
- `/mcp` is a compatibility redirect to `/docs/assistants/overview`; there is no
  current `app/pages/mcp.vue`.
- Docs Markdown twins, docs entries in `llms.txt` and `llms-full.txt`, sitemap
  entries, and RSS feeds are generated by `modules/generated-surfaces.ts` during
  `bun run generate`.
- The homepage and Vue-owned legal/marketing routes keep authored Markdown
  alternates in `public/`; see the public-content runbook for the exact split.

## Commercial offer and learning boundary

- The Creator entry offer is a seven-day card-backed trial: $0 today, then
  $24/month unless it is canceled before the trial ends. After Bitter Checkout
  accepts the payment method and starts the trial, Billing shows the
  provider-owned exact cancel-before time and scheduled first charge.
- The trial accepts one recording up to two hours and includes $5 of agent work
  for whole-recording analysis, the First Cut, and continued direction.
- Agent work is the trial's processing boundary. There is no customer-facing
  revision counter or trial export counter. Trial exports are watermarked;
  clean exports begin after paid conversion.
- Customers can top up exactly $20, $50, or $100 of agent work during an active
  trial or paid plan. A top-up never starts paid Creator early; early activation
  requires a separate explicit $24 authorization. Purchased agent work survives
  a later lapse.
- BitterClip's built-in agent is the default operator. Claude, ChatGPT, and
  other MCP clients are optional peer operators of the same workbench.
- Public code may contain truthful claims and neutral interaction events. Cost
  evidence, conversion targets, customer evidence, abuse analysis, and funnel
  interpretation stay in the adjacent private product repository.

See [commercial claims and instrumentation](docs/runbooks/commercial-instrumentation.md)
for the cross-repository authority order and neutral event contract. Product
behavior must ship and be runtime-verified before this public site promises it.

## Deployment

- Pushes to `main` trigger the BitterGrid deployment hook.
- The normal site build runs the existing checked-in Artifact selection. It does
  not call the baker.
- `bun run generate` creates `.output/public`; the Docker image copies that
  static output into nginx.
- `/up` is the production health check.

## Normal verification

```bash
bun run docs:audit
bun run artifact:status
git diff --check
bun run generate
bun run qa:smoke
```

`artifact:status` is informational by default. A dirty cinematic boundary does
not slow or block an unrelated website deployment; it means only that the next
intentional ISO4 release must render or reconcile those inputs before promotion.
